# Link Groupy

## Register

product

## Platform

web

## Users

You, DevKrishna — a developer who shares links from your phone to yourself via WhatsApp and wants them organized in a searchable, categorized dashboard. Others may self-host the same stack, but the surface is designed for a single user's workflow: send a link from anywhere, review it later on a dark desktop dashboard.

## Product Purpose

A lightweight, self-hosted read-later app that turns WhatsApp-shared URLs into an organized, searchable link library. Each link is fetched, categorized by an LLM, summarized, and displayed in a minimal dark dashboard. The system is honest about what it can't access — no fabricated content, no empty summaries.

Success looks like frictionless capture from anywhere (WhatsApp → API) and fast, focused review on the dashboard.

## Positioning

The link manager that doesn't get in the way. Capture from WhatsApp, review on a Linear-inspired dark dashboard, trust that inaccessible content is honestly labeled.

## Brand Personality

Focused, honest, minimal. Expert confidence — the interface is spare and intentional, never decorative. The system tells the truth about what it can and can't do (no fabricated summaries, no fake content previews). Like the tools it's inspired by (Linear, modded terminal UIs), it trusts the user to handle complexity when needed, but defaults to clarity.

## Anti-references

- Bloated bookmark managers (Pocket, Raindrop.io, Pinboard) — feature creep, social layers, recommendations, content algorithms
- Notion-like warm/light reading interfaces — this is a scanning tool, not a reading app
- Decorative dashboards — no charts, no widgets, no data visualization for its own sake

## Design Principles

**Honesty above all.** Never fabricate content. If a page blocks access, label it clearly. The LLM summary is empty when the content is unreachable. Every status communicates a real state.

**Focused by default.** Every feature serves the single purpose of collecting and organizing links. No recommendations, no social features, no content algorithm. A tool, not a platform.

**Expert confidence.** Dark canvas, translucent surfaces, whisper borders. Information density is high but controlled by typographic hierarchy and generous spacing. The interface recedes; the content leads.

**Personal scale.** Designed for one user (or a handful). No multi-tenant architecture, no onboarding flows, no permission systems. The tool adapts to how you work, not the other way around.

## Accessibility & Inclusion

Dark and light themes, toggled from the nav bar. WCAG AA contrast targets for body text. Reduced-motion-friendly transitions.
